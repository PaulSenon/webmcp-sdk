**No release yet.** The first release will be `0.1.0`: define, implement, register and discover WebMCP tools with Standard Schema validation, plus React bindings.

Once released, every version's notes are in:

- [`packages/webmcp-sdk/CHANGELOG.md`](https://github.com/PaulSenon/webmcp-sdk/blob/main/packages/webmcp-sdk/CHANGELOG.md), written by Changesets;
- [GitHub releases](https://github.com/PaulSenon/webmcp-sdk/releases), one immutable release per version with the exact tarball.

While the version is `0.x`, breaking changes are released as **minor** versions.
